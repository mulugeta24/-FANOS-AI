# API Documentation

This folder documents the FANOS AI application APIs and platform integrations.

## Current API Scope

The active API is implemented in backend/app/api/v1/ and is still the runtime contract for the current application.

## Planned API Documentation

- Authentication and identity flows
- Event ingestion and normalisation
- Incident APIs
- Detection and AI prediction APIs
- Response and prevention APIs
- Vendor and SIEM integration APIs

## Important Note

The implementation currently lives in the backend service, and this documentation area is intended to organize the technical API guidance without duplicating runtime code.
