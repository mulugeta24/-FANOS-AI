# Detection Flow

## Detection Pipeline

```text
Security sources
  ↓
Event collection
  ↓
Normalization
  ↓
Rule-based detection
  ↓
AI model scoring
  ↓
Risk classification
  ↓
Threat correlation
  ↓
Incident creation
  ↓
Response and prevention
```

## Current Project Status

The active detection logic is implemented across backend/app/ai and backend/app/api. The intent of the new documentation structure is to capture the logical flow without altering working implementation.
