# Response Flow

## Response Sequence

```text
Alert / Incident
  ↓
Risk prioritization
  ↓
Operator review
  ↓
Prevention action
  ↓
Block / rate limit / isolate / notify
  ↓
Follow-up authorization and reporting
```

## FANOS AI Response Model

The response model is intended to connect detection output to SOC operations and prevention workflows, with future automation layered on top of the current backend APIs.
