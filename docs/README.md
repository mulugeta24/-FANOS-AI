# FANOS AI Documentation

This folder contains the platform architecture, API reference, security model, deployment guidance, and operational documentation for the FANOS AI cybersecurity ecosystem.

## Documentation Map

- Architecture: docs/architecture/
- API: docs/api/
- Security: docs/security/
- Deployment: docs/deployment/
- Guides: docs/guides/

## Platform Scope

FANOS AI is an enterprise SOC platform for detecting, correlating, prioritizing, and responding to cyber threats across web, network, cloud, and endpoint environments.

The runtime application remains in the existing backend/ and frontend/ directories. The docs folder is used to organize the architectural roadmap and future platform expansions.
